# Flutter Creations brand assets

The user-supplied logo is preserved in `logo-original.png`.

- `logo-transparent.png`: full logo for light page headers.
- `logo-white.png`: full logo with a white backing for dark footers and mobile menu headers.
- `butterfly.png`: butterfly mark only, with no brand text.
- `icon-16.png`, `icon-32.png`, `icon-48.png`: small browser icon sizes.
- `icon-192.png`, `icon-512.png`: web app shortcut icons.
- `apple-touch-icon.png`: white-backed Apple shortcut icon.
- Root `favicon.ico`: browser favicon containing the butterfly mark only.

Artwork preparation used the built-in image generation/editing tool. Web-size exports were produced from the resulting transparent assets; the source image remains unchanged.
